# SISTEM MANAJEMEN BIOSKOP

## Deskripsi
Program Sistem Manajemen Bioskop merupakan project UTS mata kuliah Pemrograman Berorientasi Objek (OOP) yang dibuat menggunakan bahasa pemrograman Java.

## Tujuan
Membuat program sederhana untuk mengelola data film, studio, tiket, dan antrean pemesanan tiket.

## Daftar Class
1. Film.java – Mengelola informasi film.
2. Studio.java – Mengelola informasi studio.
3. Tiket.java – Mengelola data tiket.
4. AntrianTiket.java – Mengatur antrean menggunakan ADT Queue.
5. Bioskop.java – Mengelola sistem bioskop.
6. Main.java – Menjalankan program dan menampilkan menu utama.

## Konsep OOP
- Class dan Object
- Encapsulation
- Constructor
- Method
- Relasi antarclass
- Abstract Data Type (ADT) Queue
